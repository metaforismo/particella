# Particella

Scegli un terreno in Italia. Particella incrocia catasto, piani urbanistici, rischi e contesto
da fonti pubbliche ufficiali e ti dice cosa ci puoi costruire — con la fonte accanto a ogni dato.

> Stato: in sviluppo attivo. La documentazione completa arriva con la prima release.

## Sviluppo

```bash
npm install
npm run dev
```
